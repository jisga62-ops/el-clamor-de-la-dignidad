# El Clamor de la Dignidad

Sitio web editorial académico sobre derechos humanos, realidad constitucional y justicia en Guatemala.

## Archivos

- `index.html`: estructura semántica y contenido periodístico.
- `styles.css`: sistema visual responsive en marfil, café, negro y rojo sangre.
- `script.js`: menú móvil, barra de progreso, animaciones de entrada, modo lectura y alto contraste.

## Uso

Abre `index.html` directamente en un navegador. Para una vista local con servidor, desde esta carpeta ejecuta:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Dirección editorial

La composición evita depender de fotografías externas: las áreas visuales funcionan como placeholders artísticos en CSS y además incluyen la sugerencia de imagen que podría reemplazarlas en una producción final. Las fuentes enlazadas al final del sitio corresponden a organismos oficiales y sirven como punto de partida para una bibliografía académica más extensa.

El texto es divulgativo y académico. No constituye asesoría jurídica.
